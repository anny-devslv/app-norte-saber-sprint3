# Norte Saber - Sprint 3 🚀

**Integrantes:** Kauany Silva e Yasmin Santiago

O **Norte Saber** é um aplicativo que conecta profissionais voluntários a microempreendedores e cidadãos vulneráveis para fornecer orientação técnica gratuita em áreas como Jurídico, Saúde, Contábil e Negócios.

### Estrutura do Repositório:
Abaixo, nos arquivos deste repositório, você encontra a estrutura técnica que desenvolvemos para esta Sprint:
* **Login.jsx:** Estrutura e lógica visual do Front-end em React.
* **app.py:** Lógica de Back-end, conexão de API e rotas em Python.
* **norte_saber_db.sql:** Estrutura completa do Banco de Dados (DDL) e inserção de dados fictícios para testes (DML).
